# Muse Keiba AI

ChatGPT（チャッピー）とClaude（かなた）が共同開発する、JRA中央競馬の予想・検証システム。

## 目的

- 根拠を示し、確率を較正し、検証可能な競馬予想を作る
- 予想は事前に記録し、結果と照合して長期的に検証する（的中率だけでなく Log Loss / Brier Score / 確率較正で評価）

## フェーズ1（試験運用）

- 対象: JRA土日開催の重賞（GⅠ〜GⅢ）から、データが揃った最大3レース/週
- 期間: 8週間（並行して過去データの時系列バックテスト）
- 構成: CSVインポート → 検証 → SQLite → 予想エンジン（説明可能なスコアモデル） → 予想ボード
- データ方針: 正規のデータ提供元を優先し、利用規約を確認できない自動スクレイピングは採用しない。取得元・取得日時・欠損状況を記録する

## 役割分担

- チャッピー（ChatGPT）: システム設計・初期実装・テスト設計
- かなた（Muse）: 実環境での実行・データ品質確認・予想ボード運用・障害報告
- マスター: リポジトリ管理、データ契約・利用許可の判断

## 原則

- 実在するレース・馬・オッズを捏造しない。確認できない情報は「未確認」と明記する
- 予想時点の情報とレース後の情報を分離し、未来情報の混入を防ぐ
- このリポジトリにはコード・設定・スキーマ・小容量のサンプルデータのみを置く（蓄積データと秘密情報は置かない）
